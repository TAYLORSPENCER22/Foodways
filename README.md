# Foodways

**Status:** In Progress

I started this project in summer 2026 — not yet in a runnable state. 

An interactive map for exploring the world through food. Click a country to see the dishes that define it — origin stories, ingredients, and imagery.

## Features

- Interactive world map built with Mapbox GL
- Country food cards with descriptions, ingredients, and stories
- Filterable/searchable sidebar for browsing countries and dishes
- Full-stack setup: React + Vite on the client, Express + Prisma on the server

## Tech Stack

**Client**
- React + TypeScript
- Vite
- Mapbox GL JS

**Server**
- Node.js + Express
- Prisma ORM
- PostgreSQL (Neon)
